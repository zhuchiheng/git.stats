# Git Stats - VS Code 扩展

一个优雅的 VS Code 扩展，用于可视化团队代码贡献情况。通过交互式图表和直观的界面，帮助了解团队成员的工作情况。

## 使用方式

点击 VS Code 状态栏中的 Git Stats 图标即可打开统计界面。

![Git Stats Screenshot](resources/screenshot.png)

## 功能特点

### 核心功能
- 交互式饼图展示贡献分布
- 时间序列折线图展示提交趋势
- 按小时的提交/行数分布图
- 作者活跃度热力图（日期 × 小时）
- 提交信息词频分析（支持中文分词）
- 目录/文件代码所有权分析（主要作者及占比）
- 连续提交记录追踪（每位作者的当前与最长连续天数）
- 文件修改排行榜（按提交数取前 100）
- 可拖拽和调整大小的图表容器
- 实时数据更新

### 健康检查
- 高危文件排行（按 bug 密度：把 fix/bug/hotfix/revert 提交映射到它改动过的文件）
- 源码/测试改动同步率，并列出最需要补测试的高频改动文件
- 机器人账号识别（dependabot、renovate、CI 账号）与遵循 `.mailmap` 的作者身份解析
- 健康检查报告 CSV 导出

### 多仓库与筛选
- 多仓库工作区支持：仓库与分支下拉选择器
- 跨仓库统计合并
- 开发者筛选（作用于所有图表与表格）
- 灵活的时间范围选择：
  - 自动范围（全部历史）
  - 最近一周 / 一月 / 三月 / 半年 / 一年 / 三年
  - 自定义日期区间

### 导出
- CSV 导出（汇总表、文件统计表与健康检查报告）
- PNG 导出（任意图表）

## 安装方法

1. 从 VS Code 插件市场安装
2. 在 VS Code 中打开任意 Git 仓库
3. 点击状态栏中的 Git Stats 图标即可开始使用

- 现代简洁的界面设计
